# Security Policy

## Reporting a Vulnerability

The Core Promo maintainers take security issues seriously. Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately to [info@corepromo.com](mailto:info@corepromo.com).

Include as much of the following information as you can:

- The type of issue and its impact
- Step-by-step instructions or a proof of concept to reproduce the issue
- Affected versions (Frappe, ERPNext, Core Promo)
- Possible mitigations, if you have thought of one

You should receive a response within a few days. We appreciate your efforts to responsibly disclose your findings, and will keep you updated throughout the process.
